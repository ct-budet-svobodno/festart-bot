# ФЕСТАРТ · Telegram-бот фестиваля

Бот собирает баллы за посещение зон по QR-кодам, показывает прогресс на карте
площадки и позволяет обменять баллы на призы у стойки выдачи.
Весь контент — зоны, мастер-классы, призы, тексты, баллы — правится
прямо в Telegram командой `/admin`, в любой момент, включая день мероприятия.

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и впишите токен от [@BotFather](https://t.me/BotFather).
**Токен никому не пересылайте и не коммитьте в git.**

Заполните базу примерами, чтобы было с чем работать:

```bash
.venv/bin/python -m scripts.seed
```

Запустите бота:

```bash
.venv/bin/python -m app.bot.main
```

## Админка

Всё управление живёт внутри бота. Команда `/admin` доступна организаторам
с ролью «Суперадмин» или «Администратор».

### Два способа получить доступ

**1. Список ID в `.env` — постоянные админы.** Впишите Telegram ID через запятую:

```
ADMIN_TG_IDS=123456789,987654321
```

Эти люди получают права суперадмина автоматически при первом обращении к боту.
Отключить или понизить их изнутри бота нельзя — только правкой `.env` и перезапуском.
Это страховка: даже если приглашения протухли или базу пересоздали, вход останется.

Свой ID человек узнаёт командой **`/id`** в боте и присылает вам.

**2. Ссылки-приглашения — для всех остальных.** Суперадмин заводит организатора
через `/admin → 👥 Организаторы`, выбирает роль и отправляет персональную ссылку.
Ссылка одноразовая и привязывается к первому открывшему её аккаунту.

Если ни того, ни другого ещё нет, ссылку для первого суперадмина выдаст скрипт:

```bash
.venv/bin/python -m scripts.invite
```

Что есть в админке: сводка, рубильники (регистрация / начисление / выдача),
призы, зоны, мастер-классы, факультеты, настройки и тексты, поиск участника,
выгрузка CSV и архивы печатных плакатов — всё приходит файлами прямо в чат.

## Как это работает

**Зоны.** У каждой зоны свой неугадываемый код. Админка отдаёт готовый плакат A4
с QR — можно сразу в печать. Участник наводит камеру, попадает в бота,
получает баллы. Повторный скан баллов не даёт.

**Регистрация.** Если человек впервые открыл бота через QR зоны, бот сначала
проводит регистрацию, а потом досчитывает эту зону — баллы не теряются.

**Призы.** Организатор наводит камеру на личный QR участника — открывается
его собственный чат с ботом с карточкой участника. Выбирает приз, участник
подтверждает списание у себя. Двойное подтверждение закрывает и ошибку
организатора, и списание по подсмотренному чужому коду.
Если QR не читается — команда `/find` и шестизначный код участника.

**Баллы.** Хранятся журналом операций, а не одним числом. Любую ошибку
видно в истории и можно откатить, ничего не затирая.

## Команды

| Команда | Что делает |
|---|---|
| `python -m app.bot.main` | Запуск бота |
| `python -m scripts.seed` | Демо-данные |
| `python -m scripts.invite` | Ссылка-приглашение для суперадмина |
| `python -m scripts.smoke` | Проверка логики бота |
| `python -m scripts.smoke_admin` | Проверка логики админки |
| `python -m scripts.tests` | Регрессии: гонки, лимиты, клавиатуры |
| `python -m scripts.reset --content` | Снести зоны, МК и призы |
| `python -m scripts.tests` | Регрессионные тесты: гонки, дабл-клики, лимиты |
| `python -m scripts.broadcast --dry-run` | Посмотреть итоговую рассылку |
| `python -m scripts.broadcast` | Разослать итоги дня |

## Структура

```
app/
  config.py          настройки из .env
  db.py              подключение к базе
  models/            таблицы
  services/          бизнес-логика, общая для бота и админки
  bot/               Telegram-бот на aiogram
scripts/             seed, smoke, broadcast
```

## Прод

```bash
docker compose up -d --build
```

Перед боевым запуском обязательно:

- перевести `DATABASE_URL` на Postgres
- проверить, что `BOT_USERNAME` совпадает с реальным именем бота — иначе QR-коды поведут не туда
- наружу ничего не открывать: бот сам ходит в Telegram и входящих соединений
  не принимает — ни домена, ни HTTPS, ни проброса портов не нужно
